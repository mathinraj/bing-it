What's New

bing it v1.5.2

New features & improvements

Default Search Count

Set your preferred search count in Settings so the popup always starts with your number. No more adjusting every time.

Info Tooltips on Settings

Hover over the (i) icons next to each setting to see a clear explanation. Great for new users figuring out what each option does.

Rate & Promo System

A non-intrusive rating prompt and rotating promo banner help you discover other useful extensions and share your feedback.

Update Notifications

A blue banner now appears in the popup and settings when a new version is available, so you never miss an update.

Pin-to-Toolbar Guide

On first install, a helpful banner guides you to pin bing it to your toolbar. Auto-detects when pinned and confirms it.

Feature Request & Support Strip

Submit feature requests or bug reports directly from the settings page. Plus a support strip with donate and rate buttons.

Remote Query Pool

Search queries now update from a remote source automatically, so you always get fresh, diverse searches — even without Google Trends.
